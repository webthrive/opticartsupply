Keep large drawings, plans, artwork, and project documents organized in the Safco Facil Flat File. Five wide drawers provide horizontal storage for documents that are difficult to keep in standard filing cabinets.

The steel cabinet is available in Small and Medium sizes for different document formats. Each drawer includes a rear hood and hinged front depressor to help keep stored sheets flat, while a courtesy stop prevents the drawer from pulling completely out during regular use.

Choose Between Small and Medium Facil Flat Files

Safco offers the Facil Steel Flat File in two sizes. The Small 4969LG has 37-inch-wide drawers with 25.25 inches of drawer depth, while the Medium 4972LG increases drawer depth to 31.5 inches and width to 43 inches.

Store Drawings, Plans, Artwork, and Other Large Documents

Standard vertical filing cabinets aren't built for oversized sheets. The Safco Facil Flat File provides wide horizontal storage for materials that need to remain flat and accessible.

Architectural drawings, engineering documents, artwork, maps, plans, and other large sheets can be separated across five drawers. Teams working on several projects can assign individual drawers to specific jobs instead of mixing active documents in one large storage area.

The rear hood and hinged front depressor help hold sheets in position inside each drawer. These parts also help limit curling along document edges during storage.

Five Drawers for Active and Archived Files

Each Safco Facil cabinet can hold up to 300 sheets under Safco's active filing capacity. Capacity increases to 450 sheets for semi-active filing and 600 sheets for inactive material.

The different capacities allow the cabinet to serve both working files and longer-term document storage. A design team might keep current project drawings in frequently opened drawers while using other drawers for completed plans or reference material.

The Small model lists a 60-pound drawer capacity. For heavier collections, document weight and distribution should be considered alongside the available drawer dimensions before loading the cabinet.

Built for Regular Access to Large Files

Large sheets can become difficult to manage when drawers are heavy or opened throughout the day. Safco equips the Facil Flat File with heavy-duty nylon rollers to support drawer movement during regular filing and retrieval.

Courtesy stops prevent drawers from rolling completely open when users pull them forward. Chrome handles run across the drawer fronts, giving users an easy grip without handling the stored documents.

Each drawer also includes a label holder. Offices can label files by project number, client, year, department, drawing type, or another system that matches their workflow.

Stack Safco Facil Flat Files for More Storage

Safco Facil Flat Files can be stacked when a single five-drawer cabinet does not provide enough storage. Multiple cabinets can add drawer capacity vertically without requiring a separate footprint for every unit.

Safco states that Facil units can be stacked up to two high when used with the matching closed base. A high base supports one flat file and raises the cabinet to a more accessible working height.

The Small and Medium cabinets use different matching bases, so the base should be selected according to the flat file model. Safco offers closed and high-base options for both cabinet sizes.

Small Facil Flat File Base Options

The 4970LG Closed Base is made for the Small 4969LG flat file. It measures 40.25 inches wide, 24 inches deep, and 4.75 inches high.

The 4971LG High Base is also designed for the Small model. Its 20.5-inch height raises a single cabinet farther from the floor while maintaining the 40.25-inch cabinet width.

Medium Facil Flat File Base Options

The 4973LG Closed Base pairs with the Medium 4972LG cabinet. It measures 46.25 inches wide, 30 inches deep, and 4.75 inches high.

The 4974LG High Base provides a taller setup for one Medium cabinet. It measures 46.25 inches wide, 31.75 inches deep, and 20.75 inches high.

Where to Use a Safco Facil Flat File

Safco Facil Flat Files fit workspaces where oversized documents need to stay organized without being folded or rolled. Their horizontal drawer layout is especially useful when teams regularly retrieve, review, update, and return large sheets.

Common applications include:

🎨 Design studios storing layouts and presentation materials

The five-drawer format also works for teams that need separation between active projects. Labels on each drawer can turn one cabinet into a simple project-based filing system.
